- Pull-based enrollment gateway (ADR 0005) + distroless Fargate images (ADR 0006) + production deploy plumbing (ADR 0007: Aurora + KMS + ACME + Fargate + SSM).
- Observability: nebula data-plane metrics, node_exporter + Alloy, gateway + harbor-collect metrics → Prometheus, Fargate logs → Loki, monitoring node.
- Admin console (React SPA, `-tags ui`): fleet/devices/IPAM/usertrust/joinkeys/cloudtrust/policy/rollout pages, served on :443 — but dev mock-IdP login.

**CODE-COMPLETE / DEPLOY-THREADED but NOT rolled out (off by default)**

- Console SAML SSO (Entra): SAML code path + bootstrap wiring exist; poc still runs the dev mock-IdP.

**Major remaining themes**

- CA & config-signing key rotation (M8): entire milestone unstarted; trust roots can't yet rotate online.
